Font-Face Rule

The @font-face rule allows you to define your own fonts. You can use this rule to include local fonts in your web pages. The @font-face rule has the following syntax:

@font-face {
    font-family: 'MyFont';
    src: url('myfont.ttf');
    font-weight: normal;
    font-style: normal;
    }

            grid elements

            A grid layout consists of a parent element with one or more child elements

            The CSS Grid Layout provides several properties to control the layout of grid elements. Some of these properties include:

            • grid-template-columns: Defines the number and size of the columns in the grid.
            • grid-template-rows: Defines the number and size of the rows in the grid.
            • grid-template-areas: Defines the areas in the grid that can be used to position grid items
            Go here to see an example. Remember check the element "inspect".

            display property

            An HTML element becomes a grid container when its display property is set to grid or inline-grid. Using grid:

            
        .grid-container {
            display: grid;
          
        }
            Go

            Using inline-grid 

            
       .inline-grid-container {
            display: inline-grid;
            
        }
            Go

            All direct children of the grid container automatically become grid items.

            Grid Columns

            The vertical lines of grid items are called columns.

            To create grid columns, you can use the grid-template-columns property. This property takes a comma-separated list of values, where each value represents the width of a column. The width of each column is determined by the sum of the values in the list.

            Grid Rows

            The horizontal lines of grid items are called rows.

            To create grid rows, you can use the grid-template-rows property. This property takes a comma-separated list of values, where each value represents the height of a row. The height of each row is determined by the sum of the values in the list.

            Grid Gaps

            The spaces between each column/row are called gaps.

            To control the size and spacing of the grid gaps, you can use the following properties:

            • grid-column-gap: Sets the horizontal gap between grid columns.
            • grid-row-gap: Sets the vertical gap between grid rows.
            • gap: Sets both the horizontal and vertical gap between grid columns and rows.
            • grid-gap: Sets both the horizontal and vertical gap between grid columns and rows using a single value.
            • column-gap
            • row-gap

            grid lines

            Grid lines are the vertical and horizontal lines that separate grid cells. The lines between columns are called column lines. The lines between rows are called row lines.
